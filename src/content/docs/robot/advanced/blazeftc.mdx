Using the BlazeFTC library, you may run your code much faster than is typically possible.
Blaze runs in the background, "behind" the SDK and polls data without any user input at all.
On the Control Hub or on a USB Expansion Hub, a slow mode Bulk Read hook can easily provide data at 500 hz.
For more information on how that works, or to accelerate i2c calls, check out the [BlazeFTC Readme](https://github.com/owenpmckenna/blaze_ftc).

## Installation

Open `TeamCode/build.gradle` and add the following to your `dependencies` block:

```groovy
implementation 'dev.anygeneric:blazeftc:BLAZE_VERSION'
```

<Aside type="tip" title="">
  Replace the `BLAZE_VERSION` with the latest Blaze version. At the time of writing, this is version `0.1.67`. More up to date info can be found [here](https://github.com/owenpmckenna/blaze_ftc#normal-usage).
</Aside>

Then add the following to the `repositories` block to allow Gradle to find it:

```groovy
maven {
    url 'https://maven.anygeneric.dev/'
}
```

## Usage

To take advantage of Blaze via [`NextOpMode`](/robot/nextopmode/), annotate your OpMode with `@BlazeEnabled`
and pass a `BlazeBulkReadHook` as an extra constructor argument:

<Tabs syncKey="language">
<TabItem label="Kotlin">

```kotlin
@NextTeleop(name = "My Teleop")
@BlazeEnabled
class MyTeleop(robot: MyRobot) : NextOpMode(robot, BlazeBulkReadHook(Type.EXPANSION_HUB, false)) {
    override fun periodic() {
        Telemetry.log("Status", "Running")
    }
    override fun onExpansionHubBulkData() {
        //Run PID loops here
    }
}
```

</TabItem>
<TabItem label="Java">

```java
@NextTeleop(name = "My Teleop")
@BlazeEnabled
public class MyTeleop extends NextOpMode {
    public MyTeleop(MyRobot robot) { super(robot, new BlazeBulkReadHook(Type.EXPANSION_HUB, false)); }
    @Override
    public void periodic() {
        Telemetry.log("Status", "Running");
    }
    @Override
    public void onExpansionHubBulkData() {
        //Run PID loops here
    }
}
```
