This tutorial will walk you through creating a subsystem all the way to creating an OpMode.
You'll write commands, group those commands into routines, and put everything together into a real autonomous OpMode, including following a path with Pedro Pathing.

## What's in this tutorial

- **Commands**
  Writing individual actions your subsystem can perform.

- **Command Groups**
  Sequencing and combining commands into full routines.

- **Autonomous**
  Assembling everything into a working autonomous OpMode.

- **Pedro Pathing**
  Following a path as part of your autonomous routine.
