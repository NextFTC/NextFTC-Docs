`NextColorDistanceSensor` combines a color sensor and an optional distance sensor into one class.

## Creating a NextColorDistanceSensor

<Tabs syncKey="language">
<TabItem label="Kotlin">

```kotlin
// By Lynx Module and I2C bus, recommended
val sensor = NextColorDistanceSensor(RobotController.controlHub, 0)

// Using your configuration name
val sensor = NextColorDistanceSensor("colorSensor")
```

</TabItem>
<TabItem label="Java">

```java
// By Lynx Module and I2C bus, recommended
NextColorDistanceSensor sensor = new NextColorDistanceSensor(RobotController.controlHub(), 0);

// Using your configuration name
NextColorDistanceSensor sensor = new NextColorDistanceSensor("colorSensor");
```

</TabItem>
</Tabs>

Both constructors accept an optional `hasDistance` parameter:

| Parameter     | Type      | Default | Description                                                    |
| ------------- | --------- | ------- | -------------------------------------------------------------- |
| `hasDistance` | `Boolean` | `false` | Whether to also create a distance sensor from the same sensor. |

## Usage

### `update()`

Reads the color sensor (and distance sensor, if present) and refreshes the cache.
Call this once per loop, before reading anything.
It's recommended to put this in your `periodic` for your `Mechanism`..

<Tabs syncKey="language">
<TabItem label="Kotlin">

```kotlin
sensor.update()
```

</TabItem>
<TabItem label="Java">

```java
sensor.update();
```

</TabItem>
</Tabs>

### `isWithinDistance(threshold, unit)`

True if the distance sensor senses an object within `threshold`, in the given unit.

<Tabs syncKey="language">
<TabItem label="Kotlin">

```kotlin
if (sensor.isWithinDistance(4.0)) { ... } //defaults to CM
```

</TabItem>
<TabItem label="Java">

```java
if (sensor.isWithinDistance(4.0)) { ... } //defaults to CM
```

</TabItem>
</Tabs>

### `isColor(profile)`

True if the cached color reading matches the given `ColorProfile`.

<Tabs syncKey="language">
<TabItem label="Kotlin">

```kotlin
if (sensor.isColor(green)) { ... }
```

</TabItem>
<TabItem label="Java">

```java
if (sensor.isColor(green)) { ... }
```

</TabItem>
</Tabs>

### `isColorWithinDistance(profile, threshold, unit)`

True if the cached color reading matches `profile` and an object is within `threshold`, in the given unit.

<Tabs syncKey="language">
<TabItem label="Kotlin">

```kotlin
if (sensor.isColorWithinDistance(green, 4.0)) { ... } //defaults to CM
```

</TabItem>
<TabItem label="Java">

```java
if (sensor.isColorWithinDistance(green, 4.0)) { ... } //defaults to CM
```

</TabItem>
</Tabs>

### `debug()`

Single-line telemetry string showing the current RGB, HSV, and distance readings.
Useful for calibrating `ColorProfile`s.

<Tabs syncKey="language">
<TabItem label="Kotlin">

```kotlin
telemetry.addLine(sensor.debug())
```

</TabItem>
<TabItem label="Java">

```java
telemetry.addLine(sensor.debug());
```

</TabItem>
</Tabs>

## NextColor

`NextColor` stores a color, either as RGB or HSV.
HSV is recommended for most cases, since it's more stable under different lighting conditions.

<Tabs syncKey="language">
<TabItem label="Kotlin">

```kotlin
val lime = NextColor.hsv(100f, 0.9f, 0.85f)

val sameColor = NextColor.rgb(lime.red, lime.green, lime.blue)
```

</TabItem>
<TabItem label="Java">

```java
NextColor lime = NextColor.Companion.hsv(100f, 0.9f, 0.85f);

NextColor sameColor = NextColor.Companion.rgb(lime.getRed(), lime.getGreen(), lime.getBlue());
```

</TabItem>
</Tabs>

## ColorProfile

`ColorProfile` describes a target color and the tolerances, to match your readings.
These can be used for `isColor()` or `isColorWithinDistance()`.

<Tabs syncKey="language">
<TabItem label="Kotlin">

```kotlin
val green = ColorProfile(
    space = ColorSpace.HSV,
    color = NextColor.hsv(130f, 0.7f, 0.6f),
    tolerance = NextColor.hsv(20f, 0.3f, 1f),
)
```

</TabItem>
<TabItem label="Java">

```java
ColorProfile green = new ColorProfile(
    ColorSpace.HSV,
    NextColor.hsv(130f, 0.7f, 0.6f),
    NextColor.hsv(20f, 0.3f, 1f)
);
```

</TabItem>
</Tabs>

| Parameter   | Type         | Description                                                               |
| ----------- | ------------ | ------------------------------------------------------------------------- |
| `space`     | `ColorSpace` | The color space to compare in: `RGB` or `HSV`.                            |
| `color`     | `NextColor`  | The target color to match against.                                        |
| `tolerance` | `NextColor`  | How far each channel can deviate from `color` and still count as a match. |
