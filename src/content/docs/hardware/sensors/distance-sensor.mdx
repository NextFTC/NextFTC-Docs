`NextDistanceSensor` is a lightweight wrapper for a distance sensor that caches the last reading.

## Creating a NextDistanceSensor

<Tabs syncKey="language">
<TabItem label="Kotlin">

```kotlin
// By Lynx Module and I2C bus, recommended
val sensor = NextDistanceSensor(RobotController.controlHub, 0)

// Using your configuration name
val sensor = NextDistanceSensor("distanceSensor")
```

</TabItem>
<TabItem label="Java">

```java
// By Lynx Module and I2C bus, recommended
NextDistanceSensor sensor = new NextDistanceSensor(RobotController.controlHub(), 0);

// Using your configuration name
NextDistanceSensor sensor = new NextDistanceSensor("distanceSensor");
```

</TabItem>
</Tabs>

## Usage

### `update()`

Reads the distance at that moment and refreshes the cache.
Call this once per loop, before reading anything.
It's recommended to put this in your `periodic` for your `Mechanism`.

<Tabs syncKey="language">
<TabItem label="Kotlin">

```kotlin
sensor.update()
```

</TabItem>
<TabItem label="Java">

```java
sensor.update();
```

</TabItem>
</Tabs>

### `isWithinDistance(threshold, unit)`

True if the distance sensor senses an object within `threshold`, in the given unit.

<Tabs syncKey="language">
<TabItem label="Kotlin">

```kotlin
if (sensor.isWithinDistance(4.0)) { ... } //defaults to CM
```

</TabItem>
<TabItem label="Java">

```java
if (sensor.isWithinDistance(4.0)) { ... } //defaults to CM
```

</TabItem>
</Tabs>
